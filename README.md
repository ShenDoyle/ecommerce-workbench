# ecommerce-workbench

Benchyard 基座电商工作台——多品牌多店铺、文件导入、只读分析+模拟执行。

## 架构
基于 Benchyard 模块体系（manifest.json 声明 type/host/requires/entry），模块包通过 GitHub Release 发布。

## 模块
1. workbench 总览（多品牌多店铺概览）
2. brand-store（品牌与店铺管理）
3. data-import（文件导入与数据质量）
4. product-catalog（商品与编码管理）
5. order-analytics（订单与运营分析）
6. inventory-logistics（库存与物流分析）
7. task-center（任务中心与模拟执行）
8. system-admin（权限、审计与系统管理）

## 安装
通过 Benchyard 控制台「模块管理」→ URL 安装（GitHub Release zip 链接）。
